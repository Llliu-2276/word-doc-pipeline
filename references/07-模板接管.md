# 07-模板接管（既有 docx 模板 + Markdown 正文）

本文件解决第四类文档：**没有统一排版标准、版式藏在单位模板里**的实验报告、课程设计说明书、项目申报书、NSFC 申请书、各类申请表。这类文档改不动页面设置（模板里已经排好封面、页眉、表格框架、签字栏），所以脚本换一种做法——**读入模板，只填内容**。

## 1. 适用与不适用

| 适合 | 不适合 |
| --- | --- |
| 学校/单位给了 .docx 模板，必须按它的版式交 | 有明确排版规范、能用 profile 描述的（技术文档、学位论文、公文） |
| 模板版式复杂（封面信息表、页眉印章位、签字栏、固定栏目） | 需要脚本自己排封面、目录、页码的场合 |
| 内容以文字段落为主，夹几张表和图 | 需要脚本增删模板表格行、改合并单元格的场合 |

判断方法：**能不能用 profile 的十几个字段把这份文档的版式说清楚**？能，就用 `md2docx.py` + profile；不能（比如页眉里有校徽图片、首页是固定格式的信息表），就用模板接管。

## 2. 工作方式

```
模板.docx  ──┐
            ├─► fill_template.py ─► 输出.docx
正文.md    ──┤      （替换 {{占位符}} + 把正文渲染进 {{正文}} 锚点）
变量.toml  ─┘
```

两件事，没有第三件：

1. **占位符替换**：把 `{{名字}}` 换成变量值。正文段落、表格单元格（含嵌套表格）、页眉页脚里的占位符都会被替换。
2. **正文注入**：模板里写一个只含 `{{正文}}` 的段落，脚本把 Markdown 渲染成的段落、表格、图片按顺序插入到该位置，并删掉这个占位段落。

页面设置、页眉页脚、分节、页码域、封面、目录——**一律不碰**，模板怎么写就怎么留。

## 3. 准备模板（四步）

1. 打开单位给的模板 .docx，找到要填空的地方。
2. 把要填的文字换成 `{{名字}}`（如 `{{姓名}}`、`{{学号}}`、`{{课程}}`）。名字用中文、英文都行，**不要加空格和花括号**。
3. 在正文应当开始的位置，单独写一个段落，内容只有 `{{正文}}`（或 `{{content}}`）。
4. 另存为模板文件（建议放 `assets/templates/` 或项目 `templates/` 目录，文件名带「模板」二字，避免和成品混淆）。

模板里的其他内容（标题、栏目名、固定说明、签字栏）原样保留。

> 占位符还能放在页眉页脚和表格里：页眉写 `项目：{{项目名}}`，表格单元格写 `{{课程}}`，都会替换。**图片和勾选框不能当占位符**，需要就留在模板里手改。

## 4. 占位符规则

| 规则 | 说明 |
| --- | --- |
| 语法 | `{{名字}}`，花括号是英文半角；名字两侧允许空格（`{{ 姓名 }}` 也行，替换时去掉） |
| 中文键名 | 变量文件里的中文键**必须加引号**：`"姓名" = "张三"`（TOML 的裸键只允许 ASCII） |
| 被 Word 拆开 | 占位符在编辑过程中常被拆成多个 run（格式片段），脚本按段落拼接后的文本定位，能跨 run 替换，并保留首尾格式 |
| 保留名 | `正文`、`content` 是锚点，不当变量；`today`、`文件名` 是内置变量 |
| 未填占位符 | 打印一条警告列出名字，退出码仍为 0；加 `--strict` 时退出码为 1（可进 CI） |
| 占位符写错 | 写了 `{{姓名}}` 却没有这个变量，就保持原样留警告——不会静默删除 |

## 5. 变量从哪来

优先级从低到高：变量文件 → `--var` → 内置变量。

```toml
# 变量.toml（推荐写法：全部放进 [vars] 表）
[vars]
"姓名" = "张三"
"学号" = "2026001"
"课程" = "数据采集"
"教师" = "李四"
项目名 = "实验报告"       # 纯 ASCII 键可以不加引号
```

也可以直接在文件顶层写字符串键（不套 `[vars]`），效果相同。命令行覆盖：

```powershell
python scripts/fill_template.py 模板.docx 正文.md 输出.docx `
    --vars 变量.toml --var "姓名=张三" --var "日期=2026-11-15"
```

内置变量：`today`（`2026-11-15` 形式）、`文件名`（正文 md 的文件名，不含扩展名）。

先看模板里有哪些占位符，再准备变量：

```powershell
python scripts/fill_template.py 模板.docx --list
```

## 6. 正文注入的位置

- 模板里有 `{{正文}}` / `{{content}}` → 正文插入该段落的位置，占位段落被删除。
- 模板里没有 → 正文追加到文末，并给一条警告。**最好还是显式放锚点**，否则正文会跑到签字栏后面。
- 锚点段落要**只含占位符**：写成 `实验内容：{{正文}}` 时，插入的正文会排在整段之后、而「实验内容：」留在原地。

## 7. 谁来负责排版

| 项目 | 由谁决定 |
| --- | --- |
| 纸张、页边距、装订线、分节、页眉页脚、页码、封面、目录 | **模板**（脚本完全不动） |
| 注入段落的字体、字号、行距、首行缩进、对齐 | **profile**（`--profile`，默认 `ug-thesis-bit`） |
| 标题层级 | profile 的 `[[headings]]`，用真正的 Heading 样式（模板若定义了同名样式，以脚本写入的字体字号覆盖） |
| 表格边框 | profile 的 `table.style`（三线表 / 全线表），注入了 Markdown 表格才生效 |
| 图注表注 | profile 的 `[figure]` / `[table.caption]` |

所以选 profile 时只看**正文观感**：实验报告用 `ug-thesis-bit`，公文风格的表单用 `cn-gov`。

## 8. 命令示例

```powershell
# 先看占位符
python scripts/fill_template.py assets/templates/实验报告模板.docx --list

# 填充
python scripts/fill_template.py assets/templates/实验报告模板.docx `
    docs/实验报告/实验一.md docs/实验报告/实验一.docx `
    --profile ug-thesis-bit --vars docs/实验报告/变量.toml

# 只填变量、不要正文（比如只有封面信息的登记表）
python scripts/fill_template.py 模板.docx 输出.docx --vars 变量.toml
```

## 9. 与校验器的关系

模板接管的产物在 `docProps/custom.xml` 里写 `wdp_mode = template`。`check_docx.py` 看到这个标记就**跳过版式校验**（页面、页眉页脚、页码、表格边框都由模板决定，和 profile 比没有意义），只输出一行说明：

```
[OK] docs/实验报告/实验一.docx  (profile ug-thesis-bit / 模板接管：版式由模板决定，未做版式校验)
```

正文的**内容**检查（`check_md.py`）照旧，转换前先跑一遍。

## 10. 限制（都在模板里手工处理）

1. 不支持条件、循环、重复区块（没有 `{{#each}}`）。要生成 10 行表格就写 10 行 Markdown 表格，或用模板自带的表 + 手填。
2. 不支持改模板表格的行数/合并单元格；模板里的空表保持空表。
3. 页眉页脚的占位符只替换**模板已经定义过**的页眉页脚；模板没定义偶数页页眉，脚本不会替你新建。
4. 页码域、目录域、交叉引用都是模板自带或 Word 手改；脚本不写也不更新。
5. 反复在同一份已填充的文档上运行会重复注入正文（模板应当保持未填状态，每次从模板生成）。
6. 模板里的图片、印章、勾选框不动；需要按变量换图（如不同学校的校徽）时，维护多份模板。

## 11. 验收清单

- [ ] `--list` 出的占位符，和 `变量.toml` 的键一一对应（多出的键无害，缺的键会警告）
- [ ] 输出里搜不到 `{{`（Word 里 Ctrl+F 搜 `{{`）
- [ ] 正文出现在 `{{正文}}` 的位置，没有跑到签字栏后面
- [ ] 页眉页脚、封面、签字栏与模板一致
- [ ] 注入段落的字体字号行距符合所选 profile（抽查首段）
- [ ] 表格边框：注入的表格是三线表/全线表，模板原有表格没被改动
- [ ] 图片数量对得上，没有被固定行距裁切
- [ ] `check_md.py` 对正文 md 无错误；`check_docx.py` 输出「模板接管」说明
