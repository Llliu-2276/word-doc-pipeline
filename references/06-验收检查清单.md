# 06 验收检查清单

适用范围：每份文档从 Markdown 源文件到 docx、PDF 交付前的逐项核对。读者为文档作者或执行转换的代理。按"md 完成后 → docx 转换后 → 提交前"三段执行，`[ ]` 为未勾选；全部勾选才可提交。命令均在项目根目录执行，路径含中文时加引号。

## 一、md 完成后（转换前）

- [ ] 文件为 UTF-8（无 BOM）编码，中文内容使用全角标点。
- [ ] `python scripts/check_md.py "<本文件.md>"` 退出码为 0（无禁用语法、无图片缺失、图注表注格式正确）。
- [ ] 未使用会被转换丢弃的语法：代码块（` ``` `）、Markdown 链接、嵌套列表、`####` 及更深标题、内联 HTML。四级标题改用 `**4.4.1 标题**` 加粗段落。
- [ ] 标题层级从 `#` 开始，不跳级；正文标题只到 `###`。
- [ ] 图片语法统一为 `![图 X-Y 说明](images/figX-Y.png)`（alt 文本即图注，脚本自动置于图片下方居中）；表注写在表格上方且为 `**表 X-Y 说明**`，与表格之间可隔空行但不得隔正文段落。
- [ ] 图表按章连续编号，无跳号/重号；正文中有"如图 X-Y""见表 X-Y"的引用。
- [ ] `images/` 下图片文件齐全，md 引用与文件名逐一对应；PNG 宽度不小于 1600 像素。
- [ ] 表格无合并单元格、无单元格内换行（python-docx 不支持，只能在 md 层规避）。
- [ ] 无"待补""TODO""XXX""（略）"等占位内容。
- [ ] 术语统一（如 Element Plus、Spring Boot），同一概念全文一种写法。
- [ ] 未手工插入空格缩进、手工编号；列表只用 `-` 与 `1.`。

## 二、docx 转换后（排版验收）

- [ ] 转换命令退出码为 0，且输出中文件缺失告警为 0 条；有告警立即回查 md 图片路径。
- [ ] 批量重建时先跑 `python scripts/build_docs.py docs --dry-run`，确认只包含本批要处理的文档再执行。
- [ ] `python scripts/check_docx.py "<本文件.docx>" --project "<页眉项目名>"` 退出码为 0。
- [ ] 页面为 A4：`21.00 × 29.70 cm`，非 Letter（`21.59 × 27.94 cm`）。
- [ ] 页边距：上下 2.54 cm、左右 3.18 cm。
- [ ] 页眉为项目名（宋体小五）；页脚页码居中，格式 `- 1 -`。
- [ ] 标题：一级黑体三号、二级黑体小三、三级黑体小四且加粗；段前段后 0.5 行、无首行缩进。
- [ ] 正文：中文宋体小四、英文/数字 Times New Roman，两端对齐，首行缩进 2 字符（24 pt）。
- [ ] 正文行距为固定 22 磅；图片所在段落为 1.5 倍行距且图片未被裁切。
- [ ] 图注在图片下方居中、表注在表格上方居中，均为宋体小五。
- [ ] 三线表：上下框线 1.5 磅、表头下框线 0.75 磅，无竖线与内横线；表头加粗；跨页表格标题行重复。
- [ ] docx 图片数 = md 图片引用数（若已补封面再加封面图），命令见下方"一键核查"。
- [ ] docx 表格数与 md 表格数对应（docx 可能多一张封面信息表，核对时扣除）。
- [ ] 封面已补：校名、文档名、信息表、日期完整，与 `docs/封面.docx` 底版风格一致。
- [ ] 目录已插入并"更新整个目录"，抽查 5 处目录页码与正文一致。
- [ ] 全文无残留批注、修订标记、高亮。

## 三、提交前（成品与仓库）

- [ ] PDF 由**定稿 docx** 用 Word"另存为 PDF"导出；docx 重出后 PDF 已同步重出（比较修改时间）。
- [ ] PDF 首页是封面：`pdftotext -f 1 -l 1 "<本文件.pdf>" -` 输出含校名与文档名。
- [ ] PDF 页数与 Word 中页数一致；页面尺寸为 A4（MediaBox `595 x 842`，不是 `612 x 792`）。
- [ ] 文件成对且同名：`docs/<文档类型>/<名称>.md`、`.docx`、`.pdf` 三件齐备，目录归属正确。
- [ ] 文档内编号、封面日期、版本号一致。
- [ ] `git status` 只包含预期的 md/docx/pdf；无 `~$` 临时文件、无 `__pycache__`。
- [ ] `.gitignore` 已覆盖 `~$*.docx` 等 Office 临时文件；不提交中间产物。
- [ ] 跨文档一致性：术语、模块编号、角色名、表号与《选题报告》《功能分析说明书》《数据库设计说明书》口径一致。
- [ ] 内容层面：所有图表都在正文被引用；图表内容与正文描述一致；无占位、无前后矛盾结论。

### 一键核查（命令可直接复制，2026-11-10 实测可执行）

```powershell
# 页面尺寸与页边距（应输出 21.00 x 29.70 cm 与 2.54/2.54/3.18/3.18）
python -c "import docx,sys; s=docx.Document(sys.argv[1]).sections[0]; print('%.2f x %.2f cm' % (s.page_width.cm, s.page_height.cm), 'margins %.2f/%.2f/%.2f/%.2f' % (s.top_margin.cm, s.bottom_margin.cm, s.left_margin.cm, s.right_margin.cm))" "<本文件.docx>"

# 页眉/页脚文本（页眉应含项目名，页脚应为页码域而非纯文本）
python -c "import docx,sys; d=docx.Document(sys.argv[1]); s=d.sections[0]; print('header:', repr(s.header.paragraphs[0].text) if s.header.paragraphs else 'none'); print('footer:', repr(s.footer.paragraphs[0].text) if s.footer.paragraphs else 'none')" "<本文件.docx>"

# 内嵌图片数（排除 word/media/ 目录项）
python -c "import zipfile,sys; z=zipfile.ZipFile(sys.argv[1]); print(len([n for n in z.namelist() if n.startswith('word/media/') and not n.endswith('/')]))" "<本文件.docx>"

# 表格对象数
python -c "import docx,sys; print(len(docx.Document(sys.argv[1]).tables))" "<本文件.docx>"

# PDF 页数与页面尺寸
python -c "import re,sys; b=open(sys.argv[1],'rb').read(); print('pages:', len(re.findall(rb'/Type\s*/Page[^s]', b))); m=re.findall(rb'/MediaBox\s*\[([^\]]*)\]', b); print('mediabox:', m[0] if m else 'none')" "<本文件.pdf>"
```

判断方法补充：

- 字体无法用上面一行命令整体核对时，在 Word 中选中标题/正文看"字体"框；中文名以 `w:rFonts/@w:eastAsia` 为准，`run.font.name` 只反映西文字体。
- 图片是否裁切只能目检：逐张看图片上下边缘是否完整、图注是否被压。
- 目录页码一致性：Word 中按住 `Ctrl` 点目录条目应跳到对应标题。
- 重出 docx 后必须重做封面、目录、更新域、PDF 四步；此顺序错任一步，前面勾选的项全部作废，需重勾。
