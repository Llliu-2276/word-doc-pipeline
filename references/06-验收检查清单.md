# 06 验收检查清单

适用范围：每份文档从 Markdown 源文件到 docx、PDF 交付前的逐项核对。读者为文档作者或执行转换的代理。按"md 完成后 → docx 转换后 → 提交前"三段执行，`[ ]` 为未勾选；全部勾选才可提交。命令均在项目根目录执行，路径含中文时加引号。文中列出的具体数值（A4、2.54/3.18、宋体小四、22 磅、9pt 图注等）都是**默认 profile `ug-thesis-bit`** 的取值；用了 `--profile` 时，以那份 profile 的数值为准，本文的数值项相应替换。

## 一、md 完成后（转换前）

- [ ] 文件为 UTF-8（无 BOM）编码，中文内容使用全角标点。
- [ ] `python scripts/check_md.py "<本文件.md>"` 退出码为 0（无禁用语法、无图片缺失、图注表注格式正确）；文档类型不是默认时加 `--profile`。
- [ ] 未使用会被转换丢弃的语法：代码块（` ``` `）、Markdown 链接、嵌套列表、内联 HTML。四级标题：profile 未定义 `[[headings]] level = 4` 时改用 `**4.4.1 标题**` 加粗段落；定义了 level 4 时才写 `#### 4.4.1 标题`。
- [ ] 标题层级从 `#` 开始，不跳级；正文标题只到 `###`（或 profile 已定义的 `####`）。
- [ ] 图片语法统一为 `![图 X-Y 说明](images/figX-Y.png)`（alt 文本即图注，脚本自动置于图片下方居中）；表注写在表格上方且为 `**表 X-Y 说明**`，与表格之间可隔空行但不得隔正文段落。
- [ ] 图表按章连续编号，无跳号/重号；正文中有"如图 X-Y""见表 X-Y"的引用。
- [ ] `images/` 下图片文件齐全，md 引用与文件名逐一对应；PNG 宽度不小于 1600 像素。
- [ ] 表格无合并单元格、无单元格内换行（python-docx 不支持，只能在 md 层规避）。
- [ ] 无"待补""TODO""XXX""（略）"等占位内容。
- [ ] 术语统一（如 Element Plus、Spring Boot），同一概念全文一种写法。
- [ ] 未手工插入空格缩进、手工编号；列表只用 `-` 与 `1.`。

## 二、docx 转换后（排版验收）

- [ ] 转换命令退出码为 0，且输出中文件缺失告警为 0 条；有告警立即回查 md 图片路径。
- [ ] 转换与校验用的是**同一个** `--profile`；`python scripts/profile.py --check <名>` 通过。
- [ ] profile 里 `verified = false` 的块，若转换或校验时出现"未核实"提示，已确认该取值与本项目规范一致（否则按规范改 profile）。
- [ ] 批量重建时先跑 `python scripts/build_docs.py docs --dry-run`，确认只包含本批要处理的文档再执行。
- [ ] `python scripts/check_docx.py "<本文件.docx>" --project "<页眉项目名>"` 退出码为 0（非默认类型再加 `--profile`）。
- [ ] 页面为 A4：`21.00 × 29.70 cm`，非 Letter（`21.59 × 27.94 cm`）。
- [ ] 页边距：上下 2.54 cm、左右 3.18 cm。
- [ ] 生成标记存在且一致：docx 的 `docProps/custom.xml` 里有 `wdp_profile`，值与本次 `--profile` 相同（`check_docx.py` 首行会打印「生成自 <profile>」；不一致直接报错，这是 K12 假差异的根治手段）。
- [ ] 若 profile 设了 `page.gutter`（装订线）：每节 `w:pgMar/@w:gutter` 与 profile 一致；若设了 `page.mirror = true`：`settings.xml` 有 `w:mirrorMargins`，且已知正文前可能多一张不带页码的空白页（K14，属正常版式）。
- [ ] 若 profile 设了 `structure.chapter_break`（`new_page`/`odd_page`）：每章第一个标题前有分节符，且**各章页码连续**（不是每章从 1 重编——分节会克隆 `w:pgNumType`，脚本已清掉，验收时抽查第 2 章首页页码）。
- [ ] 若 profile 定义了 `[[headings]] level = 4`：`####` 生成的是「标题 4」样式（导航窗格可见），不是加粗段落；否则确认没有误用 `####`。
- [ ] 页眉为项目名（宋体小五）；页脚页码居中，格式 `- 1 -`。
- [ ] 标题：一级黑体三号、二级黑体小三、三级黑体小四且加粗；段前段后 0.5 行、无首行缩进。
- [ ] 正文：中文宋体小四、英文/数字 Times New Roman，两端对齐，首行缩进 2 字符（24 pt）。
- [ ] 正文行距为固定 22 磅；图片所在段落为 1.5 倍行距且图片未被裁切。
- [ ] 图注在图片下方居中、表注在表格上方居中，均为宋体小五。
- [ ] 三线表：上下框线 1.5 磅、表头下框线 0.75 磅，无竖线与内横线；表头加粗；跨页表格标题行重复。
- [ ] 若 profile 用 `body.line_spacing.mode = "grid"`（公文）：每节有 `w:docGrid`（`linePitch` = 版心高 ÷ 行数），正文段落行距为固定「版心高 ÷ 行数」（公文 225mm ÷ 22 ≈ 29 磅）；导出 PDF 数第一页，应是 22 行后分页（只用 docGrid 不写固定行距，实测每页只有 17 行）。
- [ ] 若 `table.style = "grid"`（全线表）：`w:tblBorders` 六条边都在且非 `nil`，线宽为 `table.border.grid`（`cn-gov` 为 0.5 磅）。
- [ ] 若 `page_number.position = "odd-even-outside"`：`settings.xml` 有 `w:evenAndOddHeaders`，奇数页页脚右对齐、偶数页页脚左对齐，格式为 `— 1 —`（`format = "emdash"`）。
- [ ] 若 profile 禁用了页眉（`header_footer.header_enabled = false`）：页眉为空，且 `check_docx.py` 未报缺页眉。
- [ ] docx 图片数 = md 图片引用数（若已补封面再加封面图），命令见下方"一键核查"。
- [ ] docx 表格数与 md 表格数对应（docx 可能多一张封面信息表，核对时扣除）。
- [ ] 封面已补：校名、文档名、信息表、日期完整，与 `docs/封面.docx` 底版风格一致。
- [ ] 目录已生成并"更新整个目录"（转 docx 时用 `--toc`，或在 Word 中手工插入），抽查 5 处目录页码与正文一致；启用 `--toc` 时正文页码从 1 起、前置页按 `front_numbering` 处理。
- [ ] 全文无残留批注、修订标记、高亮。

### 模板接管文档（`fill_template.py` 产物，另加以下几条）

模板接管的页面、页眉页脚、页码、封面、目录**由模板决定**，第二段里与之相关的项不再适用；改成核对：

- [ ] `fill_template.py --list` 列出的占位符与变量文件键对应，无「没填」警告（或已确认剩余项要手工补）。
- [ ] 输出里搜不到 `{{`（Word 里 Ctrl+F 搜 `{{`，正文、表格、页眉页脚各搜一遍）。
- [ ] 正文出现在 `{{正文}}` 锚点位置（不是跑到签字栏或末尾）；锚点段落本身已不存在。
- [ ] 页眉页脚、封面、签字栏、模板原有表格与模板一致，没有被脚本改动。
- [ ] 注入段落的字体、字号、行距、首行缩进符合所选 `--profile`（抽查首段与一个标题）。
- [ ] 注入的表格边框符合 profile（三线表/全线表），模板自带的表格保持原样。
- [ ] 图片数量与 md 中的 `![...]()` 一致，没有被固定行距裁切。
- [ ] `check_docx.py` 输出「模板接管：版式由模板决定，未做版式校验」而不是一堆版式差异。

## 三、提交前（成品与仓库）

- [ ] PDF 由**定稿 docx** 用 Word"另存为 PDF"导出；docx 重出后 PDF 已同步重出（比较修改时间）。
- [ ] PDF 首页是封面：`pdftotext -f 1 -l 1 "<本文件.pdf>" -` 输出含校名与文档名。
- [ ] PDF 页数与 Word 中页数一致；页面尺寸为 A4（MediaBox `595 x 842`，不是 `612 x 792`）。
- [ ] 文件成对且同名：`docs/<文档类型>/<名称>.md`、`.docx`、`.pdf` 三件齐备，目录归属正确。
- [ ] 文档内编号、封面日期、版本号一致。
- [ ] `git status` 只包含预期的 md/docx/pdf；无 `~$` 临时文件、无 `__pycache__`。
- [ ] `.gitignore` 已覆盖 `~$*.docx` 等 Office 临时文件；不提交中间产物。
- [ ] 跨文档一致性：术语、模块编号、角色名、表号与《选题报告》《功能分析说明书》《数据库设计说明书》口径一致。
- [ ] 内容层面：所有图表都在正文被引用；图表内容与正文描述一致；无占位、无前后矛盾结论。

### 一键核查（命令可直接复制，2026-11-15 实测可执行）

```powershell
# 页面尺寸与页边距（应输出 21.00 x 29.70 cm 与 2.54/2.54/3.18/3.18）
python -c "import docx,sys; s=docx.Document(sys.argv[1]).sections[0]; print('%.2f x %.2f cm' % (s.page_width.cm, s.page_height.cm), 'margins %.2f/%.2f/%.2f/%.2f' % (s.top_margin.cm, s.bottom_margin.cm, s.left_margin.cm, s.right_margin.cm))" "<本文件.docx>"

# 页眉/页脚文本（页眉应含项目名，页脚应为页码域而非纯文本）
python -c "import docx,sys; d=docx.Document(sys.argv[1]); s=d.sections[0]; print('header:', repr(s.header.paragraphs[0].text) if s.header.paragraphs else 'none'); print('footer:', repr(s.footer.paragraphs[0].text) if s.footer.paragraphs else 'none')" "<本文件.docx>"

# 内嵌图片数（排除 word/media/ 目录项）
python -c "import zipfile,sys; z=zipfile.ZipFile(sys.argv[1]); print(len([n for n in z.namelist() if n.startswith('word/media/') and not n.endswith('/')]))" "<本文件.docx>"

# 表格对象数
python -c "import docx,sys; print(len(docx.Document(sys.argv[1]).tables))" "<本文件.docx>"

# 生成标记（profile 名、页面尺寸、页眉页脚目录是否输出）
python -c "import zipfile,re,sys; z=zipfile.ZipFile(sys.argv[1]); print(z.read('docProps/custom.xml').decode('utf-8'))" "<本文件.docx>"

# 装订线与镜像边距（每节 gutter 与应用级 mirrorMargins）
python -c "import docx,zipfile,sys; d=docx.Document(sys.argv[1]); print('gutter:', [round(s.gutter.cm,2) for s in d.sections]); z=zipfile.ZipFile(sys.argv[1]); print('mirror:', b'mirrorMargins' in z.read('word/settings.xml'))" "<本文件.docx>"

# 分节与页码（各节类型与 pgNumType，检查是否每章重编）
python -c "import docx,sys; from docx.oxml.ns import qn; d=docx.Document(sys.argv[1]); print([(s.start_type, (s._sectPr.find(qn('w:pgNumType')).attrib if s._sectPr.find(qn('w:pgNumType')) is not None else None)) for s in d.sections])" "<本文件.docx>"

# 文档网格（每节 docGrid；linePitch 应等于版心高 twips ÷ 行数）
python -c "import docx,sys; from docx.oxml.ns import qn; d=docx.Document(sys.argv[1]); print([(g.get(qn('w:type')), g.get(qn('w:linePitch')), g.get(qn('w:charSpace'))) if (g:=s._sectPr.find(qn('w:docGrid'))) is not None else None for s in d.sections])" "<本文件.docx>"

# 全线表与奇偶页页码（grid 表六条边、evenAndOddHeaders）
python -c "import docx,zipfile,sys; d=docx.Document(sys.argv[1]); from docx.oxml.ns import qn; t=d.tables[0]._tbl if d.tables else None; b=t.tblPr.find(qn('w:tblBorders')) if t is not None else None; print('tblBorders:', [(e.tag.split('}')[1], e.get(qn('w:val'))) for e in b] if b is not None else None); z=zipfile.ZipFile(sys.argv[1]); print('evenAndOdd:', b'evenAndOddHeaders' in z.read('word/settings.xml'))" "<本文件.docx>"

# PDF 页数与页面尺寸
python -c "import re,sys; b=open(sys.argv[1],'rb').read(); print('pages:', len(re.findall(rb'/Type\s*/Page[^s]', b))); m=re.findall(rb'/MediaBox\s*\[([^\]]*)\]', b); print('mediabox:', m[0] if m else 'none')" "<本文件.pdf>"
```

判断方法补充：

- 字体无法用上面一行命令整体核对时，在 Word 中选中标题/正文看"字体"框；中文名以 `w:rFonts/@w:eastAsia` 为准，`run.font.name` 只反映西文字体。
- 图片是否裁切只能目检：逐张看图片上下边缘是否完整、图注是否被压。
- 目录页码一致性：Word 中按住 `Ctrl` 点目录条目应跳到对应标题。
- 重出 docx 后必须重做封面、目录、更新域、PDF 四步；此顺序错任一步，前面勾选的项全部作废，需重勾。
