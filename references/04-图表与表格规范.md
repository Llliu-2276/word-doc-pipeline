# 04 图表与表格规范（制作流程、文件命名与内容要求）

## 适用范围

本文件面向需要为中文课程设计文档、技术文档配图配表的作者与 AI 代理，规定图表的制作方式、源文件与导出文件的命名存放、图注表注与正文引用写法、内容与可读性要求，以及从绘图到插入 md、重出 Word 的完整流程。

本文件讲「怎么做、放哪里、叫什么、写什么」。成品 Word 的字体字号、三线表线宽、图注表注边距等参数及其在脚本中的落实，见 [02-Word格式规范.md](02-Word格式规范.md)；Markdown 语法限制见 [03-Markdown写作约束.md](03-Markdown写作约束.md)。

## 一、总则

- 每张图、每张表都必须服务于正文论点，并在正文中被引用、被解释，不做装饰性图表。
- 图表按章编号，一章一套序列：第 4 章依次为图 4-1、图 4-2、表 4-1、表 4-2；附录用图 A-1、表 A-1。
- 一图一主题、一表一用途；图幅过大、列数过多的图表要拆分，拆分后各自独立编号。
- 图表的可编辑源文件与导出成品成对保存、同名同目录，md 只引用导出成品。
- 图表清单与进度由「图表绘制说明.md」维护，它是中断恢复与交付核对依据，新增或改图必须同步更新。

## 二、绘图工具与文件管理

### 2.1 工具选择

- 结构图、流程图、ER 图、功能结构图用 Visio 手绘，保留 `.vsdx` 源文件，便于后续改图。
- 数据趋势图、统计图可用 Excel 或 ECharts 导出图片；系统界面类图用真实截图，不用无法再编辑的位图拼贴作正式插图，截图类材料单独管理（见第八节）。

### 2.2 文件命名与存放

| 文件 | 命名 | 位置 | 用途 | 是否提交 |
| --- | --- | --- | --- | --- |
| Visio 源文件 | `fig4-1 系统总体ER图.vsdx` | `docs/<文档>/images/` | 可编辑母版 | 提交 |
| 导出图片 | `fig4-1.png` | 同目录 | md 引用的成品图 | 提交 |
| Visio 锁文件 | `~$$fig4-1 系统总体ER图.vsdx` | 打开 Visio 时自动出现 | 临时锁，关闭后消失 | 不提交 |
| 证据原图 | `E-A-01-应用商店.png` | `docs/<文档>/证据截图/<竞品>/` | 原始截图存档 | 提交 |
| 证据副本 | `E-A-01-应用商店.png` | `docs/<文档>/images/screenshots_docx/` | md 引用的副本 | 提交 |

补充约定：

- 图片文件名与图号对应：`figX-Y.png` 中 X 是章号、Y 是本章序号，一个字符都不能省，便于脚本与人工核对。
- md 只引用 `images/` 下的 PNG，`.vsdx` 绝不被引用；Visio 锁文件以 `~$$` 开头，已在 `.gitignore` 中，提交前确认 `git status` 无锁文件。
- 提交版需要换章号时（例如正文图号从第 4 章改为第 3 章），复制图片改名、同步改 md 图注，两处必须同时改。

### 2.3 PNG 导出规格

| 项目 | 要求 | 本项目实际 |
| --- | --- | --- |
| 宽度 | 不小于 1600 像素，保证 A4 打印清晰 | 1800～3000 像素 |
| 格式 | PNG，白底，不透明 | PNG |
| 缩放 | 导出时锁定纵横比 | 按 Visio 页面比例 |
| 内容 | 无网格线、无参考线、无选中框、无空白大边 | 导出前关闭网格与参考线 |
| 图内文字 | 图中不写「图 x-x」图号与图名，图注由 md 生成 | 一致 |
| 宽高比 | 避免超长竖图，超过 A4 单页可视高度的图拆成两张 | 宽高比不超过约 1:2 |

## 三、图注、表注与正文引用

### 3.1 位置与写法

| 元素 | 位置 | 对齐 | 字号 | md 写法 |
| --- | --- | --- | --- | --- |
| 图注 | 图片下方 | 居中 | 宋体小五 | 图片语法的方括号内：`![图 4-1 系统总体ER图](images/fig4-1.png)` |
| 表注 | 表格上方，可隔空行 | 居中 | 宋体小五 | 表格上方独立一行：`**表 4-1 实体与关联表清单**` |
| 三级标题后直接出现的表 | 表注在表格上方 | 居中 | 宋体小五 | 与上式相同，表注与表格之间不留正文段落 |

- 图注文字格式为「图 x-x 图名」，图名不加标点、不加书名号、不写「如下图所示」。
- 表注文字格式为「表 x-x 表名」，表名写成名词短语；图注、表注都不写句末句号，它们是称名不是句子。
- 表注与表格之间可以空一行（脚本会跳过空行、确认下方是表格后渲染为表注），但中间不能插入正文段落；紧贴表头写最稳妥。

### 3.2 正文引用

- 正文用「如图 4-1 所示」「见表 4-1」的固定句式；不要写「如下图」「见下表」，因为成品翻页后方位不成立。
- 先引用后出现：先写引用句，图或表紧随其后；不允许出现未被正文引用的图表。
- 引用编号必须与图注表注编号完全一致，改图号后全文搜索旧编号一并改掉。
- 同一图在同一节内只引用一次，后续用「该图」「上图」指代。
- 引用句要说明图表表达什么，例如「如图 4-1 所示，六张 ER 图按业务域聚类」，而不是只写「如图 4-1 所示」。

### 3.3 图表与章节的关系

- 图表放在它所论证的章节内，紧跟相关正文，不集中堆到章末或附录。
- 一张图跨两页时，优先缩小图幅或拆分，而不是让 Word 自动断开。
- 图表不得替代正文：表 4-1 列出的内容，正文仍需给出结论性描述。

## 四、表格内容规范

### 4.1 三线表

- 成品统一为三线表：上下框线 1.5 磅、表头下框线 0.75 磅、无竖线与内部横线、表头加粗且跨页重复、表内文字 10pt；线宽与字号由脚本落实，作者只负责内容（参数细节见 02-Word格式规范.md）。作者不设合并单元格、不设单元格内换行，脚本无法表达这两者，且会导致列数错位甚至转换失败。

### 4.2 表头与列

- 第一列一般是序号或名称，便于正文按行引用。
- 表头写字段名与单位，例如「长度（cm）」「数量（个）」，不在单元格里重复单位。
- 列数尽量不超过 6 列；超过时先合并同类列或缩短列名。
- 同一文档内同类表格的列顺序保持一致，便于横向对照。

### 4.3 表内文字

| 项目 | 规则 |
| --- | --- |
| 语言 | 中文名词短语，不用完整句子 |
| 术语 | 与正文、图注完全一致，不用同义替换 |
| 数字 | 半角，小数位数统一 |
| 空值 | 用一字线「—」，不写「无」「N/A」混用 |
| 长内容 | 超过一行的描述移到正文或拆成多行 |

## 五、长表与宽表处理

| 情形 | 处理方式 | 说明 |
| --- | --- | --- |
| 表格跨页 | 允许，表头自动重复 | 避免让只有表头加一行数据孤悬页首 |
| 表格行数过多（超过两页） | 拆成多张表，各自编号与表注 | md 中不写「续表」表注，它会被当普通加粗段落 |
| 列数过多（超过 6 列） | 合并同类列、缩写列名、纵向拆表 | 优先减少列，而不是缩字号 |
| 单元格文字过长 | 改为正文分条说明 | 表格是索引，不是段落 |
| 超宽表 | 拆表；确需横向页面时在 Word 中手工插入分节并设为横向 | 脚本不支持横向页面，重新生成 docx 会丢失该设置，须在最终定稿阶段处理 |
| 附录中的大表 | 允许较长，但同样要编号、被正文引用 | 附录表用表 A-1 序列 |

## 六、图幅与可读性

- 图中文字不小于 10 磅（按 Visio 原始页面计）。成品中图片统一缩放到约 14.5cm 宽，缩放比越大小字越难读：页面越宽，越要放大字号。
- 换算方法：成品字号约等于 Visio 字号乘以 14.5 再除以 Visio 页面宽度（cm）。页面宽 14～16cm 时 10 磅基本可用；页面宽 30cm 时字号需放大到 20 磅以上。
- 主色不超过 3 种，同义元素同色；黑白打印仍能区分（不依赖颜色单独传递信息）。
- 连线用直线或正交折线，箭头方向一致，尽量减少交叉与穿越文字。
- 同类图使用同一套符号，并在「图表绘制说明.md」中声明符号约定；ER 图用陈氏符号时，实体为矩形、属性为椭圆、联系为菱形，主键属性加下划线，联系两端标注 1/N/M。
- 图中不写图号图名，不写与正文重复的整段说明；确需注释时用短语。
- 验收方式：按 A4 纸打印或在 Word 中 100% 缩放目视，所有文字与箭头可辨认即合格。

## 七、图表绘制说明.md

每套配图必须有一份说明文件，用于记录进度、约定与审查结论。历史命名不完全统一（《数据库设计说明书》为 `ER图绘制说明.md`，《功能分析说明书》《竞品分析报告》为 `图表绘制说明.md`），新文档统一命名为 `图表绘制说明.md`。

| 章节 | 必备内容 |
| --- | --- |
| 头部 | 更新日期、适用范围、本文件作用（进度与中断恢复依据） |
| 图清单与进度 | 图号、图名、类型、状态（如「已导出 PNG（1800×1200）并插入 md」） |
| 命名与存放 | `figX-Y.png` 与同名 `.vsdx` 的位置、PNG 宽度要求 |
| 符号与布局约定 | 图形符号含义、泳道或分区布局规则、颜色约定 |
| 图注清单 | 每张图的图注文字，与 md 中完全一致 |
| 审查记录 | 已核对项与遗留问题（如某子功能待补、某图待重画） |
| 后续任务 | 未完成的图、需重出的 docx |

维护规则：

- 新增图、改图、重导出 PNG、插入 md、重出 docx 后，必须同步更新状态列与文件头部日期。
- 说明文件与实际图片不一致时，以说明文件为排查起点，先核对文件是否存在、宽度是否达标、md 图注是否同步。
- 中断后恢复工作时先读该文件，凭状态列判断进度，不凭记忆。

## 八、证据截图（竞品分析、实测类）

- 命名规则：`E-<竞品代号>-<两位序号>[a/b]-<中文名>.png`，例如 `E-A-01-应用商店.png`；同一界面多张用 a/b 后缀，如 `E-A-07a-首页顶部.png`；A 为主竞品（药管家），B 为医鹿，C 为用药助手，代号对照在报告开头写明。
- 序号在组内连续，与附录截图清单表一一对应，不跳号、不复用。
- 原始截图存 `证据截图/` 的竞品子目录（可含 jpg），md 只引用转换后的 PNG 副本 `images/screenshots_docx/`，副本宽度约 800 像素用于版式排布。
- 图注写法：`![图 A-1 药管家：应用商店](images/screenshots_docx/E-A-01-应用商店.png)`，附录统一用「图 A-x」序列。
- 截图要求：界面关键信息完整、可辨认；手机号、账号等隐私必须打码；不伪造未实测界面。
- 每张截图在审查记录中给出结论（保留/替换/删除），未审查的截图不进入正文。

## 九、图片缺失、转换与核对

### 9.1 图片缺失

- 脚本对不存在的图片只打印「警告: 图片不存在，已跳过: <路径>」并继续转换，成品少图且中间没有提示，因此转换前必须先跑 `check_md.py`，转换后再核对图片数量。
- 常见原因：文件名大小写不符、png 与 jpg 混淆、图片还在 `证据截图/` 未复制到 `images/`、路径写成绝对路径或带引号。
- 处理：补齐文件或改 md 路径后重新转换；不要靠手工往 docx 里插图，下次生成会丢。

### 9.2 转换与核对

```bash
python scripts/check_md.py docs/功能分析说明书/功能分析说明书.md
python scripts/md2docx.py docs/功能分析说明书/功能分析说明书.md docs/功能分析说明书/功能分析说明书.docx --project "项目名称"
python scripts/check_docx.py docs/功能分析说明书/功能分析说明书.docx --project "项目名称"
```

- 第一步查图片存在性、图注与表注编号、禁用语法；第二步转换；第三步查页面、边距、内嵌图片数（已排除 `word/media/` 目录项）、表格是否为三线表。
- 人工再核：图片数等于 md 图片行数、每张图下方有图注、每张表上方有居中表注、无残留语法符号（井号、竖线、反引号、星号）。
- 重新生成 docx 后封面与目录会消失，需在 Word 中补排封面、重做目录（见 02-Word格式规范.md）。

## 十、制图到定稿的流程

1. 在「图表绘制说明.md」中登记图号、图名、类型，状态写「待绘制」。
2. Visio 绘制，按符号与布局约定出图，锁定纵横比导出 PNG 到 `images/`，宽度不小于 1600 像素。
3. 审查：对照正文与数据源核对内容，检查字号、颜色、连线、图内无图号，检查 PNG 宽度与清晰度。
4. 在 md 中插入图片行并写图注，正文补「如图 4-1 所示」引用句，同步说明文件状态为「已导出并插入 md」。
5. 重新生成 docx，按 9.2 核对图片数、图注、表注与残留符号。
6. 在 Word 中补封面、更新目录，导出 PDF，同步更新说明文件的日期与遗留问题。

## 十一、交付前自检清单

- [ ] 每个图号、表号都在正文中被引用，编号连续无跳号
- [ ] 图注在图片下方居中、表注在表格上方居中，格式为「图 x-x 名称」「表 x-x 名称」
- [ ] 每张图都有同名 `.vsdx` 源文件，PNG 宽度不小于 1600 像素
- [ ] 图中无网格线、无图号图名，字号在成品中可辨认
- [ ] 主色不超过 3 种，黑白打印可区分
- [ ] 表格为三线表，无合并单元格、无单元格内换行、无多余竖线
- [ ] 超长表已拆分并各自编号，未使用「续表」表注
- [ ] 证据截图命名符合 E- 规则，隐私已打码，审查记录齐全
- [ ] `git status` 中没有 Visio 锁文件
- [ ] docx 内嵌图片数与 md 图片行数一致，无残留语法符号
- [ ] 「图表绘制说明.md」状态列与实际文件一致，头部日期已更新
